
# portalCitas-CreacionUsuariosAmbitos

Automatizacion para la creacion de usuarios y ambitos del Portal de Citas.

## Flujo

1. Lectura de solicitudes desde SharePoint.
2. Limpieza y validacion de datos.
3. Generacion de plantilla de usuarios.
4. Procesamiento del resultado del portal.
5. Generacion de ambitos.

## Configuracion

Crear un archivo `.env` tomando como referencia:

`.env.example`

El archivo `.env` contiene credenciales locales y no debe subirse al repositorio.

## Instalacion

pip install -r requirements.txt
